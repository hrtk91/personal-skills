# 探索担当へ渡す情報

独立した原因探索や問い直しが判断に役立つ場合に使う。主担当が問い、調査範囲、証拠の統合、最終判断を持つ。

## 分担と境界

- 会話履歴を引き継がず、他担当の出力や主担当の暫定結論を渡さない。
- 読み取りだけに権限を制限できる環境で起動する。技術的に保証できない場合は主担当で検討し、独立した検証とは扱わない。
- 推論量と人数は問いの難しさと使える資源に合わせる。低い推論量や一定の人数を必須条件にしない。
- 外部書き込み、設定変更、破壊的な確認、再委譲は禁止する。
- 観測事実には出所を付ける。秘密情報、無関係なログ、全履歴は渡さない。

主担当の問い自体に偏りが疑われる場合は、問いや見る観点も渡さず、確定事実と決めたいことの種類から別の問い・隠れた前提を考えてもらう。役名や人数を埋めるために担当を増やさない。

## 依頼に含めるもの

- 役割と調査範囲、終了条件。
- 出所付きの観測事実と、説明したいこと。推測と未確認点を区別する。
- 判断に関係する制約と対象外。
- 一次資料への参照と、必要な箇所を探せる検索語または短い抜粋。
- 他の候補と見分けられる予測、反証条件、最小の確認方法を返す依頼。

問い直し担当には、同じ観測を別に説明する問いと、それによって変わる判断を求める。原因候補を誘導する言葉を、確定事実や依頼目的へ混ぜない。

## 依頼例

```text
添付の観測と一次資料から、原因候補と見分ける方法を検討してください。
読み取りと分析だけを行い、書き込み・設定変更・破壊的な確認・子担当の起動はしないでください。

観測事実: <出所付きの事実>
説明したいこと: <観測事象。問い直しを依頼するときは省く>
決めたいこと・制約・対象外: <今回の判断に必要な範囲>
一次資料: <参照と必要な検索語・抜粋>

原因から観測までの仕組み、支持する証拠、他の候補と分かれる予測、
反証条件、最小の確認を簡潔に返してください。
資料だけでは分からないことを推測で埋めず、必要な情報と取得方法を示してください。
結果を返したら終了してください。
```

## 統合と終了

出力は多数決や結論として採用せず、一次資料と照合する。同じ原因かどうかは、仕組み・予測・反証条件で判断する。

追加の一次資料や未探索の観点が判断を変え得る場合だけ追加確認する。候補同士をまだ見分けられないことだけを理由に人数を増やさない。証拠が揃わなければ、不足情報とその影響を残す。
