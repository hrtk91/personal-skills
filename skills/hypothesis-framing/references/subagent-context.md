# Leaf subagent へのコンテキスト

## 目的

leaf に渡すのは、独立した因果仮説を立てて識別するための最小十分な packet だけにする。親の結論に同意させる情報、他 leaf の出力、全ログは渡さない。

## dispatch packet

各 leaf に次を順に渡す。

1. **役割と境界**: leaf であり、担当軸だけを探索し、外部への書き込みや子 subagent の起動をしないこと。
2. **採用した問題設定**: 説明したい観測、決めたい意思決定、対象外の問い。
3. **確定事実**: 出所付きの観測だけ。推測を事実として混ぜない。
4. **不明点**: まだ識別できていない変数と、必要なら欠落している資料。
5. **探索で守るべき制約**: セキュリティ、期限、コスト、変更禁止範囲、利用可能な観測手段。
6. **担当軸**: 一つの主担当と、重複を避ける対象外の軸。
7. **エビデンス**: 一次資料のパス・URL・行範囲、または短い抜粋。大きな資料は source map にする。
8. **出力契約**: `SKILL.md` の固定 Leaf フォーマット、最大2仮説、証拠不足なら不足情報を返すこと。

## 渡さないもの

- 親の暫定結論、推したい解決案、優先順位
- 他 leaf の出力、集約表、多数派の見解
- 全会話履歴、無関係なログ、未整理の長い検索結果
- token、cookie、パスワード、個人情報、アクセス可能だが不要な秘密情報
- 実行してよいように見える外部変更の指示

すでに棄却した仮説は、再提案を避けるために必要なときだけ「棄却理由と反証済み条件」を短く渡す。棄却したという結論だけを渡さない。

## エビデンスの圧縮

親は詳細なエビデンスログを保持し、leaf には担当軸の判断を変え得る資料だけを渡す。

- コード・設定: ファイルパス、対象シンボル、関連する行範囲、実行時の観測を分ける。
- ログ: 全文ではなく、時刻、相関ID、失敗分類、前後の状態遷移を含む最小の連続区間にする。
- 文書・要件: 決定、制約、例外条件を抜粋し、解釈を事実として混ぜない。
- 大きい資料: source map にパスと検索語を書き、leaf に必要な箇所だけ読ませる。親の要約だけを唯一の証拠にしない。

負の結果、すでに失敗した方法、結論を覆す条件は、担当軸に関係する場合だけ必ず含める。これらを落とすと、leaf が同じ失敗を再発見する。

## prompt template

```markdown
あなたは低推論の leaf subagent です。担当軸以外の結論を出さず、
外部書き込み・設定変更・子subagent起動をしないでください。

## 問題設定
<観測事象、意思決定、対象外>

## 確定事実
- <事実>（出所: <path / URL / 時刻>）

## 不明点
- <未確認の変数>

## 制約
- <守るべき制約>

## 担当軸
<一つの軸。対象外の近接軸も明記する>

## エビデンス
- <短い抜粋または source map>

`SKILL.md` の Leaf 固定フォーマットだけで、最大2仮説を返してください。
仮説を識別できない場合は、不足している識別情報と、その情報で除外できる分岐を返してください。
```

## source map template

大きいリポジトリ、ログ、文書束には、raw artifact を丸ごと貼らず次を渡す。

```markdown
## Source map
- <path / URL>: <何が分かるか>; 読む箇所: <symbol / 行範囲>; 検索語: <terms>
- <path / URL>: <何が分かるか>; 読む箇所: <時刻範囲>; 検索語: <terms>
```

leaf が source map だけでは因果仮説を識別できないと返した場合、親は該当一次資料の最小抜粋を追加して再実行する。親の結論で穴を埋めない。

## dispatch 前の確認

- packet だけで、leaf が何を説明し、何を決めず、どの軸を見るか判別できるか。
- 確定事実と推測が分かれているか。
- leaf ごとのエビデンスが同じ結論を誘導していないか。
- 秘密情報と無関係な履歴を除いたか。
- 利用可能な agent slot を確保し、leaf からの再委譲を禁止したか。

## 回収後の確認

- 仮説が packet 内の根拠を越えて断定していないか。
- 仮説ごとに追加予測と反証条件があるか。
- 同じ因果主張を別表現で重複していないか。
- 「追加で何を読めば分岐が減るか」という不足情報の報告を、失敗ではなく有効な出力として扱ったか。
