# Wheel UI

ネイティブのスクロールとCSS Scroll Snapを土台にし、大きなwheel入力だけを補正する。細かな入力とタッチの慣性はブラウザへ任せる。見た目だけでなく「軽く回せば隣へ、続けて回せば滑らかに先へ」を守る。

## 実装の判断

- ユーザーが指定した場所へ置く。インラインの依頼をダイアログに置き換えない。確定ボタンの有無は画面の目的から決める。
- 通常のselectで十分なら独自化しない。独自ホイールが求められたときに、この方式を使う。
- 等高・有限個の候補を基本形とする。無限ループ、可変高、仮想化、多列連動が必要なら、添付サンプルの前提から外れる部分を先に設計する。
- 表示中の中央候補と、停止後の確定値を分ける。確定値の所有者は親・フォーム・URLなど既存の一箇所に保ち、途中のスクロールから保存や通信を連発しない。

## 操作感を守る要点

1. `overflow-y: auto`、`scroll-snap-type: y mandatory`、各行の`scroll-snap-align: center`を使う。上下に余白を置き、最初と最後も中央に来るようにする。
2. 中央判定はスクロール領域と行の実測位置で行う。行高だけを広げても、大きなwheel入力の飛ばしは解決しない。
3. 大きなwheel入力は、1イベントにつき隣の項目までに補正する。アニメーション中の入力は**現在位置ではなく、予定している移動先に加算**し、`scrollTo({ behavior: "smooth" })`で追従する。一定時間の入力無視、1ジェスチャー1項目への固定、毎回の瞬間移動は避ける。
4. 細かなpixel入力、横方向優位の入力、Ctrl付きズーム、キャンセル不能なイベントは標準動作へ渡す。補正するイベントだけ`preventDefault()`する。`deltaMode`を先に読み、line/pageの値をpixelとして比較しない。
5. `scrollend`で停止位置を確定する。未対応環境ではscrollの無入力時間を使う。どちらもタッチ中・予定位置へ移動中・中央からずれた状態では確定しない。
6. 確定値を親へ通知して戻ってきたとき、すでに中央にいるなら再スクロールしない。URL変更でページ上端へ戻さない。タップ・キー・外部値変更・候補変更時には古い移動先を解除し、unmount時にlistenerとtimerを片付ける。

wheelイベントと物理的な1目盛りは同一とは限らず、イベントの大きさだけでマウスとトラックパッドを完全に判別できない。上記の補正はヒューリスティック。再発時は閾値を繰り返し変える前に、問題の端末で`deltaMode`、`deltaY`、イベント間隔、移動位置を確認する。入力内容など無関係な情報は記録しない。

## 再利用するコード

Reactで実装するときは [WheelPicker.tsx](assets/WheelPicker.tsx) と [wheel-picker.css](assets/wheel-picker.css) を読む。コピー先の状態管理・デザインへ合わせて使う。日付、週、ステータス、ルーター、アイコンライブラリには依存しない。

```tsx
<WheelPicker
  label="時間"
  options={times.map(time => ({ value: time.id, label: time.label }))}
  value={selectedTime}
  onChange={setSelectedTime}
/>
```

値は一意な文字列、`value`は候補内の値を渡す。空候補は空状態を表示する。候補外の値は表示を先頭へ合わせるが、勝手に親の値を書き換えない。候補を絞った後の値の扱いは親が決める。

サンプルの行高88px、表示高220px、微小入力の境界「行高の半分」、停止判定160ms・誤差1pxは開始点であり、共通の正解ではない。非Reactでも入力補正・位置計算・停止確定の責務をUI側に閉じて同じ原理を使う。

## 表示と検証

`listbox`/`option`、一意なID、中央候補の`aria-activedescendant`と`aria-selected`、見えるフォーカス、ArrowUp/Down・Home/End、タップ、前後ボタンを用意する。矢印キーを扱ったときだけページへの既定動作を止める。reduced motionではプログラムによるsmooth移動を即時移動にする。

[検証項目と失敗例](references/validation.md) に従い、飛ばしと慣性の両方を確認する。自動テストの成功と、実機の操作感の評価を分けて報告する。ユーザーが気に入った感触を、無関係な抽象化や物理演算への置き換えで変えない。
