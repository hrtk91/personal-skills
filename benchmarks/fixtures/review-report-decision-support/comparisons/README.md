# 比較用文書の読み方

ここにある文書は、完成版の見本ではない。何を変えたときに理解しやすさが変わるかを分けて確かめるための比較材料である。

- `baseline.md`: 元の読みにくさを残した文書。
- `structure-only.md`: 用語はほぼそのままにして、結論、重要な問題、理由、修正を並べ直した文書。説明不足の用語が残るのは意図した比較条件であり、推奨する書き方ではない。
- `vocabulary-only.md`: 6件を並べる形は保ち、内部用語を普通の言葉へ直した文書。重要な問題をまとめ直していないため、これも完成版ではない。
- `rhythm-only.md`: 見出し、指摘の順序、まとめ方、用語は保ち、一文の主張数と文長の変化だけを調整した文書。

構造と用語の両方を同時に直した完成版を先に正解としない。それぞれの変更が読者の理解へ与える影響を別々に確認する。
